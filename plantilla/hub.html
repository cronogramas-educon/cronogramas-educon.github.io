¿Cómo funciona esta página?
  • Cuando alguien guarda el Excel de un curso, esta página se actualiza sola en unos minutos.
  • Cada curso tiene su propio enlace para estudiantes. Desde él no se llega a otros cursos ni a esta página: pásales solo el enlace de su curso.
  • Esta página es para el equipo. No compartas su dirección.

Cursos y periodos

Para abrir un curso nuevo, llena el formulario. El sistema crea la carpeta, el Excel de horas, el de asistencia y la página del curso.

Registrar curso nuevo

Otra forma: desde el Excel de registro
  1. Abre el Excel Registro de cursos y escribe una fila por curso. Guarda.
  2. Para un periodo nuevo, copia las filas del anterior y cambia Periodo y Carpeta del periodo. Si se vuelven a abrir cursos en el mismo periodo, cambia solo la Cohorte.
  3. En unos minutos el curso aparece en esta página con su enlace para estudiantes. Después llena el Excel del curso para publicar su cronograma.
